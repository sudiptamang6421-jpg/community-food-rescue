# FeastForward - Community Food Rescue & Surplus Sharing

This is the official GitHub repository for **FeastForward**, a web application designed to connect local surplus food from donors and businesses with community food banks, pantries, and individuals in need.

---

## 📌 Project Description

** Module:** COM109 Client-Side Development
** Coursework: ** Coursework 2 (Group Project)
** Theme: ** Community Food Rescue & Surplus Sharing Platform
** Tech: ** HTML5, CSS3 (Flexbox/Grid), JavaScript, jQuery, Bootstrap 5
